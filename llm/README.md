# llm

파티 빌더 LLM 서버. back(Django)과 **별도 서버**로 돌아간다.

## 역할
- 요청 의도 해석, 도구 호출, 파티 제안, 전략 설명
- 사실 정보(종족값, 기술, 배우는 기술, 데미지, 사용률, 레귤레이션)는 외우지 않고 **back의 API로 조회·계산**
- 파티 빌딩 페이지의 채팅 답변을 SSE로 스트리밍

## 구조 (예정)
```
llm/
  agent/       에이전트 루프, 프롬프트, 도구 정의 (도구 = back API 호출)
  providers/   API 모델 / 로컬 모델 교체 가능한 provider 추상화
  server/      채팅 API 서버 (SSE 스트리밍)
  training/    LoRA 파인튜닝 데이터 생성·학습 (3단계)
```

## 분리한 이유
- 파인튜닝·로컬 모델용 무거운 라이브러리(torch 등)가 Django에 섞이지 않음
- GPU 서버에 따로 배포 가능
